# Smart Patch — لصقة ذكية لرصد تسرّب المستحضرات المشعة أثناء الحقن الوريدي

> ⚠️ **تنبيه مهم:** جميع النتائج في هذا المستودع ناتجة عن **محاكاة حاسوبية (in silico)**،
> وليست من مرضى حقيقيين ولا من قياسات مخبرية. الهدف دراسة جدوى للفكرة قبل بنائها.

## الفكرة باختصار
لصقتان: واحدة على ذراع الحقن وأخرى مرجعية على الذراع المقابلة، وكل لصقة فيها قناتان:
- **قناة إشعاعية** (كاشف وميضي): التسرّب يُبقي النشاط عند موقع الحقن، بينما الحقنة السليمة يُغسل نشاطها.
- **قناة حرارية** (مستشعر NTC): المحلول أبرد من الجسم، والتسرّب يُبقي الجلد بارداً لدقائق، بينما التبريد الوريدي يزول خلال ثوانٍ.

ونموذج ذكاء اصطناعي (انحدار لوجستي) يصنّف كل حقنة إلى: **سليمة / احتباس وريدي / تسرّب**.

## الملفات
| الملف | الوظيفة |
|---|---|
| `physics.py` | النموذج الفيزيائي الأمامي (بلا تعلّم آلي) |
| `simulate.py` | محاكاة مونت كارلو وتحليل قابلية الكشف |
| `ai_model.py` | نموذج الذكاء الاصطناعي وتقييمه |
| `figures.py` | رسم الأشكال |
| `run_all.py` | يشغّل كل شيء ويولّد النتائج والأشكال الستة |
| `demo.py` | عرض حي لقرار الذكاء الاصطناعي على حقنات جديدة |

## التشغيل
```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run_all.py   # النتائج والأشكال (أقل من دقيقة)
.venv/bin/python demo.py      # العرض الحي
```
النتائج قابلة لإعادة الإنتاج بالضبط (بذور عشوائية ثابتة).

## أبرز النتائج (محاكاة)
- أصغر تسرّب قابل للكشف: **~2–3% من الجرعة خلال 30–60 ثانية** (القناة الإشعاعية مع كاشف مرجعي).
- القناة الحرارية وحدها ضعيفة مبكراً، وتتحسن مع الوقت (تسرّب 5% عند دقيقتين).
- في الاختبار الصعب (تسرّبات صغيرة، أوردة عميقة، احتباس وريدي قوي): القواعد البسيطة كشفت **0%**،
  ونموذج الذكاء الاصطناعي كشف **98.8%** عند معدل إنذار كاذب 5%.

## حدود العمل
- البيانات محاكاة بالكامل؛ لم يُتحقق منها بقياس حقيقي.
- عدة معاملات تقديرية (مُعلَّمة بـ ⚠ في `physics.py`).
- نتيجة الذكاء الاصطناعي تعتمد على افتراض أن الاحتباس الوريدي لا يسبب تبريداً باقياً.
- النموذج يخطئ في التسرّبات الصغيرة جداً (~1%) في الأوردة العميقة.
